# Html, css, JavaScript

### EN

Here, I will be leaving some interesting .html pages of local websites and individual .js files. The code can be edited in Visual Studio Code, but there is a separate IDE for web programming — WebStorm.

Be sure to read the HTML, CSS, JavaScript tutorial:  https://mixelte.github.io/pages/html-css-js/?ysclid=mwvsv8vk6i699286942

- .html files can be run by double‑clicking the file itself.
- .js files can be run via the Windows console or through an Visual Studio Code:
  - download and launch Visual Studio Code
  - select File
  - then select Open file and open your work folder, with .js file
  - in the left panel, open `.js` file
  - launch file in terminal Visual Studio Code: python [file name].js
