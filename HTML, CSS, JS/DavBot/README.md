# DavBot

### EN
This program is built on JavaScript and the Mineflayer API. Mineflayer is a large library that lets you create and program bots for Minecraft: you can make them respond to your messages, move along chosen or free paths, do tasks for you, protect you, and much more. The capabilities of this library are limited only by your imagination and programming skills.

Be sure to take a look doucmentation on mineflayer: https://github.com/PrismarineJS/mineflayer <br/>
Also check out the JavaScript programming language guide to understand the syntax: https://github.com/Only-tutorials/javascript-tutorial?ysclid=mwd4izywu698175420

<h4> Download library "mineflayer" in the folder with file `.js`: </h4>

- Open folder with file `.js`:
  - from Windows console: `cd /d [диск]:/[путь]/DavBot`
  - or from terminal Visual Studio Code
   
- Введите в консоль или терминал:
  - `npm install`
  - `npm init -y`
  
<h4> Launch bot: </h4>

- Write in Windows console or in terminal Visual Studio Code:
  - `node DavBot.js`


### RU
Данная программа опирается на язык программирования JavaScript и Mineflayer API. Mineflayer - большая библиотека, которая позволяет создавать и программировать ботов для игры Minecraft. Вы можете запрограммировать бота отвечать на ваши сообщения, ходить по выбранной и свободной траектории, работать за вас, защищать вас и многое другое! Возможности данной библиотеки ограничиваются лишь вашей фантазией и умением программировать!

Чтобы код для бота заработал, вам необходимо скачать Minecraft версии, которую поддерживает библиотека minelfayer. Затем создайте любой тип мира. Зайдите в этот мир и откройте игру для сети. Вы сделали вам мир Minecraft локальным сервером! Запомните порт, который вывелся в чат, его нужно будет вписать в строку: `port:` в файле бота, чтобы он подключился к вашему миру. В строку: `ip:` впишите `localhost` (ваш локальный сервер), чтобы бот присоединился именно на ваш локальный сервер. 

Обязательно посмотрите документацию по mineflayer: https://github.com/PrismarineJS/mineflayer <br/>
Также посмотрите гайд по языку программирования JavaScript, чтобы понимать синтаксис: https://github.com/Only-tutorials/javascript-tutorial?ysclid=mwd4izywu698175420

  - или через терминал Visual Studio Code
   
- Введите в консоль или терминал:
  - `npm install`
  - `npm init -y`

<h4> Запустите бота: </h4>

  - `node DavBot.js`
