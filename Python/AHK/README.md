#### EN
Download libraries "pyautogui" and "pydirectinput":

- Open folder:
  - in Windows console: `cd /d [disk]:/[path]/AHK`
  - in terminal PyCharm

- Download first library: `pip install pyautogui`
- Download second library: `pip install pydirectinput`
