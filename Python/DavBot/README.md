# DavBot

### EN
<h4> Download library "javascript": </h4>

- Open folder with file:
  - in PyCharm: `File -> Open... -> [folder]`
  - or in Windows console: `cd /d [disk]:/[path]/DavBot`

- Download library: `pip install javascript`
- Launch file:
  - in programm PyCharm
  - or from terminal Visual Studio Code: python CoordsPointer.py
  - or from Windows console: cd /d [disk]:/[path]/CoordsPointer.py


### RU
Данная программа опирается на язык JavaScript и библиотеку "mineflayer". Mineflayer - большая библиотека, в основном созданная, для языка программирования JavaScript, позволяет создавать и программировать ботов для игры Minecraft. Вы можете запрограммировать бота отвечать на ваши сообщения, ходить по выбранной и свободной траектории, работать за вас, защищать вас и многое другое! Возможности данной библиотеки ограничиваются лишь вашей фантазией и умением программировать!

Обязательно посмотрите документацию по mineflayer: https://github.com/PrismarineJS/mineflayer <br/>
Также посмотрите гайд по языку программирования JavaScript, чтобы понимать синтаксис: https://github.com/Only-tutorials/javascript-tutorial?ysclid=mwd4izywu698175420

<h4> Скачайте библиотеку "javascript": </h4>

- Откройте папку с файлом:
  - в PyCharm: `File -> Open... -> [folder]`
  - или в консоли Windows: `cd /d [disk]:/[path]/DavBot`

- Установите библиотеку: `pip install javascript`
- Запустите файл:
  - в программе PyCharm
  - или из терминала Visual Studio Code: python CoordsPointer.py
  - или из консоли Windows: сd /d [disk]:/[path]/CoordsPointer.py
