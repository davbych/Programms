### EN
<h5> Launch `.py` file in **PyCharm**. Set up a virtual environment </h5>

- Download python ( > 3.10 )
- Download and launch PyCharm
- Select `File`
- Then select `Open...` and open your work folder, with `.py` file
- In the left panel, open `.py` file
- Open settings and select `Project: [file name]`
- Then select `Python interpreter`
- Choose directory with `python.exe`

<h5> Launch `.py` file in **Visual Studio Code**: </h5>

- Download and launch Visual Studio Code
- Select `File`
- Then select `Open file` and open your work folder, with `.py` file
- In the left panel, open `.py` file
- Launch file in terminal Visual Studio Code: `python [file name].py`

### RU
Запуск `.py` файла в **PyCharm**. Настройка виртуального окружения:

- Скачайте python ( > 3.10 )
- Скачайте и запустите PyCharm
- Выберите `File`
- Затем выберите `Open...` и откройте рабочую папку, с `.py` файлом
- В левой панели откройте `.py` файл
- Откройте настройки и выберите `Project: [название файла]`
- Затем выберите `Python interpreter`
- Выберите директорию с `python.exe`

Запуск `.py` файла в **Visual Studio Code**:

- Скачайте и запустите Visual Studio Code
- Выберите `File`
- Затем выберите `Open file` и откройте рабочую папку, с `.py` файлом
- В левой панели откройте `.py` файл
- Запустите файл в терминале Visual Studio Code: `python [название файла].py`
