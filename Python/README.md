#### EN
Set up a virtual environment for **PyCharm**, in working folder: 

- Download and launch PyCharm
- Select `File`
- Then select `Open...` and open your work folder, with `.py` files
- In the left panel, open any `.py` file


#### RU
Настройка виртуального окружения для **PyCharm** в рабочей папке:

- Скачайте и запустите PyCharm
- Выберите `File`
- Затем выберите `Open...` и откройте рабочую папку, с `.py` файлами
- В левой панели откройте любой `.py` файл
