#### EN
Set up a virtual environment for **PyCharm**, in working folder: 

0\) Download and launch PyCharm

1\) Select `File`

2\) Then select `Open...` and open your work folder, with `.py` files

3\) In the left panel, open any `.py` file


#### RU
Настройка виртуального окружения для **PyCharm** в рабочей папке:

0\) Скачайте и запустите PyCharm

1\) Выберите `File`

2\) Затем выберите `Open...` и откройте рабочую папку, с `.py` файлами

3\) В левой панели откройте любой `.py` файл
