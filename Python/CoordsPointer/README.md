### EN
CoordPointer is a small utility that opens a window displaying the exact cursor coordinates at the top (The coordinates are updated 16 times per second). You can pause the updates by pressing "Space". To copy coordinates in different formats, LMB and RMB inside the window. The middle section shows the current event (copying, paused, updating), while the bottom section shows the last copied coordinates, the copy timestamp, and the format used. You can close the window with the standard Windows X button or by pressing "Escape" when the window is focused.

Documentation on TKinter: https://realpython.com/ref/stdlib/tkinter/
Documentation on Datetime: https://realpython.com/python-datetime/

<h4> Libraries "tkinter" and "datetime" already available in Python "out of the box" =) </h4>

- Launch file:
  - in programm PyCharm
  - or from terminal Visual Studio Code: `python CoordsPointer.py`
  - or from Windows console: `cd /d [disk]:/[path]/CoordsPointer.py`


### RU
Данная утилита, открывает окно, с точными координатами курсора, в верхней части окна (координаты обновляются 16 раз в секунду). Обновление координат можно остановить, нажав "Space" (пробел). Можно скопировать координаты в разных форматах, нажав в окне ЛКМ и ПКМ. В средней части окна будет отображаться текущее событие (копирование, пауза, проигрывание обновления). В нижней части окна будут отображаться последние скопированные координаты, время копирования и формат копирования. Закрыть окно утилиты можно, используя стандартный крестик Windows или нажав клавишу "Escape", когда окно активно.

Документация по TKinter: https://realpython.com/ref/stdlib/tkinter/
Документация по Datetime: https://realpython.com/python-datetime/
